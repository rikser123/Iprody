# Clients Service

 Сервис хранит данные о всех известных клиентах, когда-либо обращавшихся в нашу систему (CRM). Сам клиент является одним из основных артефактов для отделов продаж, маркетинга и обучения. Клиент может запросить продукт, завершить его и так далее.
## Необходимые для запуска переменные среды

- DB_URL
- DB_USERNAME
- DB_PASSWORD
- KEYCLOAK_ISSUER_URL
