# Payment Service

 Payment Service (далее PS) хранит данные обо всех известных платежах и их связи с соответствующими запросами на приобретение продукта поступающими от клиентов. Платеж сам по себе является основным артефактом для отслеживания статуса платежа при обслуживании конкретного клиента.

## Необходимые для запуска переменные среды

- DB_URL
- DB_USERNAME
- DB_PASSWORD
- KEYCLOAK_ISSUER_URL
